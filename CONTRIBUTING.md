# Contributing to Emargy Mail

Thank you for helping build Emargy Mail.

## Before contributing

- Discuss large product or architecture changes in an issue before implementation.
- Never use real user credentials, messages, or attachments in tests or bug reports.
- Keep AI sending behind explicit human approval.
- Keep Arabic and English behavior aligned, including keyboard navigation and RTL layout.
- Add tests for mail parsing, synchronization, and security-sensitive changes.

## Pull requests

Pull requests should be focused and explain:

1. The problem being solved.
2. The chosen approach and alternatives considered.
3. Security and privacy impact.
4. Tests performed.
5. UI screenshots for visible changes, in both directions when layout is affected.
